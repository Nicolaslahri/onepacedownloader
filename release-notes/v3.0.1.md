## One Pace Downloader 3.0.1

**Checking for new episodes works on more connections.** Refresh could fail with "Couldn't reach GitHub" even though your internet was fine. The app now:

- Connects the way browsers do, so a network with broken IPv6 no longer makes GitHub time out.
- Falls back to two mirrors of the catalog when GitHub's file server is blocked or down.
- Retries once on a hiccup, and tells you what actually went wrong (DNS, timeout, security software, and so on) instead of a generic message.

Downloads use the same faster connection setup.
