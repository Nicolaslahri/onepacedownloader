## A Windows 11 makeover, and downloads that just work again

### New look
The app has been rebuilt to look and feel like a native Windows 11 app:
- Your sources are in a navigation pane on the left.
- Text uses Segoe UI Variable.
- Icons are Windows' own.
- The app uses your Windows accent colour.
- The title bar blends into the window, with Mica on Windows 11.

Light and dark both follow your Windows setting, and the side pane folds down to icons on smaller windows.

### Fixes
- **Episodes that wouldn't download** ("no files matched the filter") work again. One Pace re-released some episodes in place, and the app now finds the new files by name.
- **English Dub no longer quietly downloads the subtitled version** when an episode has no dub yet. The download dialog tells you how many episodes that affects and lets you choose.
- **Resumed downloads that never finished are fixed.** Every finished file is also checked against its checksum, so a damaged download gets fetched again.

### New
- **Skip what you already have:** episodes already in your library are skipped when you download a batch.
- **One progress bar for the whole batch:** percentage, size and time left now cover everything you queued.
- **Update notice:** the app tells you when a newer version is out.
- **Stable Plex season numbers:** they stay the same even when One Pace adds a new arc.

### Docker
- A "Sort for Plex / Jellyfin" switch in Settings.
- Saved API keys are no longer visible in the browser.
- An optional `WEB_PASSWORD` for the web UI.
- Live progress.
- A list of anything that didn't download.
